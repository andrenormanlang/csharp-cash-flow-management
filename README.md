# 💰 C# WPF CashFlow Management 📊

A desktop application for managing personal finances and tracking cash flow.

## Features 🌟

- Track income and expenses with detailed categorization
- Monthly financial summaries and reports
- Real-time cash flow monitoring
- Smart transaction filtering and search
- Category-based expense analysis
- Export and import transaction data (JSON format)
- Clean and intuitive user interface

## Getting Started 🚀

### Prerequisites

- .NET 9.0 or later
- Windows operating system
- Visual Studio 2022 or later (recommended)

### Installation

1. Clone the repository or download the source code
2. Open `CashFlowManagement.sln` in Visual Studio
3. Build and run the application

## Usage 📱

- Add new transactions using the input form
- Filter transactions by date, category, or type
- View monthly summaries in the dashboard
- Generate detailed financial reports
- Save and load transaction data

## Key Features in Detail 🔍

### Transaction Management

- Add, edit, and delete transactions
- Categorize as expense or revenue
- Add descriptions and dates
- Automatic monthly totals

### Financial Reports

- Monthly revenue summary
- Expense breakdown
- Net cash flow calculation
- Top expense categories
- Top revenue sources

### Data Persistence

- Save transactions to JSON files
- Load previous transaction data
- Data backup and restore

## Technology Stack 💻

- C# / .NET 9.0
- WPF (Windows Presentation Foundation)
- MVVM Architecture
- JSON for data storage
